## Detalhes para Você Executar Externamente

### 1️⃣ Mascote (Bloqueador)

**Você precisa:**
- Imagens PNG/SVG (108×108px+ recomendado)
- Background transparente
- Filenames exatos:
  - `mascot-running.png` — mascote em movimento
  - `mascot-standing.png` — mascote parado

**Onde colocar:**
```
artifacts/fretex/assets/images/mascot/
├── mascot-running.png
└── mascot-standing.png
```

**Como testar:**
```bash
npx expo start
# Navegar até Inbox/Marketplace vazio → mascote deve flutuar
```

**Se não colocar:** EmptyState mostra placeholder circular cinza (funcional mas incompleto visualmente).

---

### 2️⃣ Supabase Key Rotation (Segurança)

**Acessar:**
1. https://supabase.com/dashboard
2. Projeto `ajudae_banco` (rlehpgvvevarpkkamied)
3. Settings → API

**Copiar nova `anon key`**

**Atualizar Cloudflare Pages (CRM):**
1. Pages → `ajudae-app` project
2. Settings → Environment variables
3. `VITE_SUPABASE_ANON_KEY` = new key
4. Redeploy (automático ou manual)

**App mobile:** Não precisa atualizar (chave pública é inerente ao design Expo).

---

### 3️⃣ Bucket Privado

**Acessar:**
1. https://supabase.com/dashboard
2. Projeto `ajudae_banco`
3. Storage → `provider-docs` bucket
4. ⚙️ Settings

**Alterar:** Public → Private

**CRM continuará acessando** via `getSignedUrl()` (5min TTL) — código já pronto.

---

### 4️⃣ EAS Builds (Deploy)

**Pré-requisitos:**
- EAS CLI: `npm install -g eas-cli` ou `pnpm add -g eas-cli`
- Apple Developer Account (para iOS/TestFlight)
- Google Play Console (para Android/Play Store)

**iOS (TestFlight):**
```bash
cd artifacts/fretex
eas build --platform ios --auto-submit
# Ou eas build --platform ios para manual submission
```

**Android (APK/Play Store):**
```bash
cd artifacts/fretex
eas build --platform android
```

**Pós-build checklist:**
- [ ] Splash screen amarelo #FFC90E (não laranja)
- [ ] App icon background correto
- [ ] Bottom tab bar visível
- [ ] Chat bubbles amarelas (me)
- [ ] Zero emojis em qualquer tela
- [ ] Heatmap 2 tons (cinza/amarelo)

---

### 5️⃣ Cloudflare Access + Domínio (CRM)

**Registrar domínio** (ou usar existente):
- Exemplo: `admin.ajudae.app.br` ou `crm.ajudae.app`

**Apontar nameservers para Cloudflare** (ou adicionar CNAME se já usa outro registrar).

**Em Cloudflare Pages:**
1. Projeto `ajudae-app`
2. Custom domains → adicionar novo domínio
3. Verificar DNS

**Em Cloudflare Zero Trust:**
1. Applications → `ajudae crm`
2. Edit
3. Trocar URL de `*.pages.dev` para novo domínio
4. Adicionar regra de email permitido

**Resultado:** CRM só acessível por email autorizado via Zero Trust.

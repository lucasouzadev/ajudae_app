# Handoff — UI/UX Brand Identity Implementation (6 Etapas)

**Data:** 2026-05-10  
**Branch:** `claude/review-mvp-readiness-adQuT`  
**Contexto:** Implementação completa da identidade visual Ajudaê — alinhamento de cores, eliminação de emojis, simplificação de interfaces poluídas e nova navegação role-aware.

---

## Visão Geral

O projeto tinha boa fundação técnica mas sofria de desalinhamento visual:
- Cores ligeiramente diferentes do branding oficial
- 23+ emojis espalhados (quebrava identidade icon-based)
- Telas poluídas com gradientes, badges multicoloridas, toggles com 3 mudanças simultâneas
- Falta de navegação consistente entre cliente e prestador

**Resultado:** 6 etapas implementadas, zero emojis, novo padrão visual coeso com Ionicons/MCI, brand colors precisas.

## Etapa 5 — Animações e Micro-interações

### Novo Hook: `useEntranceAnim`

**Arquivo:** `hooks/useEntranceAnim.ts` (25 linhas)

```typescript
export function useEntranceAnim(delay = 0) {
  const opacity = useRef(new Animated.Value(0)).current;
  const translateY = useRef(new Animated.Value(12)).current;

  useEffect(() => {
    Animated.parallel([
      Animated.timing(opacity, {
        toValue: 1,
        duration: 280,
        delay,
        easing: Easing.out(Easing.cubic),
        useNativeDriver: true,
      }),
      Animated.timing(translateY, {
        toValue: 0,
        duration: 280,
        delay,
        easing: Easing.out(Easing.cubic),
        useNativeDriver: true,
      }),
    ]).start();
  }, []);

  return { animStyle: { opacity, transform: [{ translateY }] } };
}
```

**Uso:** Envolver containers principais em `<Animated.View style={animStyle}>`

### Skeleton — Shimmer com LinearGradient

**Arquivo:** `components/Skeleton.tsx` (refatorado)

**Antes:** Opacity pulse (0.4 → 1 → 0.4)

**Depois:** Shimmer wave
```typescript
const shimmer = useRef(new Animated.Value(-200)).current;

useEffect(() => {
  const anim = Animated.loop(
    Animated.timing(shimmer, {
      toValue: 400,
      duration: 1200,
      useNativeDriver: true,
    })
  );
  anim.start();
}, [shimmer]);

// Renderização:
<View style={{ backgroundColor: c.bgDeep, overflow: "hidden" }}>
  <Animated.View style={[StyleSheet.absoluteFill, { transform: [{ translateX: shimmer }] }]}>
    <LinearGradient
      colors={["transparent", "rgba(255,201,14,0.15)", "transparent"]}
      start={{ x: 0, y: 0.5 }}
      end={{ x: 1, y: 0.5 }}
      style={{ width: 200, height: "100%" }}
    />
  </Animated.View>
</View>
```

## Etapa 6 — Bottom Tab Bar (Role-Aware)

### Novo Componente: `BottomTabBar`

**Arquivo:** `components/BottomTabBar.tsx` (125 linhas)

**Features:**
- Role-aware: Cliente vs Prestador (tabs diferentes)
- Design: `#1F1F1F` (Carbono Preto) bg, `#FFC90E` (Amarelo) ativo
- Ícone inativo: `rgba(255,255,255,0.4)` (branco 40%)
- Label visível apenas na tab ativa (Figtree 10px SemiBold)
- Animação: `scale` 1 → 1.12 → 1 na seleção
- **Oculta automáticamente** quando `active !== null` (serviço em progresso)

**Rotas:**

| Papel | Tabs |
|-------|------|
| Cliente | Início, Buscar, Inbox, Ajuda |
| Prestador | Início, Serviços, Inbox, Portfólio |

**Integração:** `app/_layout.tsx` — adicionado como overlay fixo no fim do AuthGate
```typescript
<View style={{ flex: 1 }}>
  <Stack ... />
  <BottomTabBar />
</View>
```
